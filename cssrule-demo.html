Animate CSS stylesheet rules directly — including pseudo-elements like ::before and ::after that can't be reached via the DOM.

01 — CSSRulePlugin

::before Pseudo-element

Animate a ::before pseudo-element's opacity to reveal a decorative accent bar. The DOM can't target pseudo-elements — CSSRulePlugin reaches into the stylesheet directly.

// animating .highlight-box::before opacity

The left accent bar is defined in a ::before rule with opacity: 0. CSSRulePlugin fades it in by modifying the stylesheet rule.

Important Notice
This content is highlighted using a ::before pseudo-element — no extra DOM nodes needed.
const rule = CSSRulePlugin.getRule(".highlight-box::before"); gsap.to(rule, { cssRule: { opacity: 1 }, duration: 0.8, ease: "power2.out" });
02 — CSSRulePlugin

::after Pseudo-element

A tooltip badge rendered via ::after is animated into view — sliding up and fading in — without touching the DOM at all.

// animating .badge::after opacity and top

The tooltip exists purely in CSS. CSSRulePlugin gets the rule and animates its opacity and top to create a pop-up effect.

Verified Component
const afterRule = CSSRulePlugin.getRule(".badge::after"); gsap.to(afterRule, { cssRule: { opacity: 1, top: "-32px" }, duration: 0.5, ease: "back.out(2)" });
03 — CSSRulePlugin

Animating :hover State

CSSRulePlugin can modify what a :hover state looks like — dynamically changing the hover appearance itself, not just triggering on hover.

// modifying .magic-btn:hover rule dynamically

Clicking the buttons below changes what the button looks like when hovered — by animating the stylesheet :hover rule. Move your mouse over the button to see the effect change.

const hoverRule = CSSRulePlugin.getRule(".magic-btn:hover"); // Changes what :hover looks like — not triggered by hover! gsap.to(hoverRule, { cssRule: { backgroundColor: "rgba(120,80,255,0.35)", color: "#f0f0f8" }, duration: 0.6, ease: "power2.out" });
04 — CSSRulePlugin

Dynamic Theme Switching

Animate the .demo-panel CSS rule's background-color and color values directly — smooth theme transitions without touching inline styles on individual elements.

// animating .demo-panel cssRule background and color

The panel's appearance is driven by its class rule in the stylesheet. Modifying the rule affects all elements with that class simultaneously.

Theme Panel
This panel's background and text color are driven by its CSS class rule — not inline styles. Switch themes to see the rule animate.
const panelRule = CSSRulePlugin.getRule(".demo-panel"); gsap.to(panelRule, { cssRule: { backgroundColor: "#f5f5f0", color: "#111118" }, duration: 0.8, ease: "power2.inOut" });

Animate a Class Rule

Dynamically animate the box-shadow on a CSS class rule to create a pulsing glow effect across all matching elements at once.

// .pulsing cssRule box-shadow animation

All three elements share the .pulsing class. Animating the rule changes all of them simultaneously — with no per-element logic needed.
