01 — CustomBounce

Basic Bounce

A ball drops and bounces using a custom ease created with CustomBounce.create(). No squash, just a clean multi-bounce arrival.

// strength: 0.6 — clean bounce, no squash

CustomBounce creates a new ease (registered as "myBounce") that drives the y position through a realistic bounce pattern.

CustomBounce.create("myBounce", { strength: 0.6, squash: 0 }); gsap.to(".ball", { y: 160, ease: "myBounce", duration: 2 });
02 — CustomBounce

Squash & Stretch

Two simultaneous tweens in a timeline — one drives y with the bounce ease, the other drives scaleX/scaleY with the paired squash ease.

// squash: 3 — heavy squash on impact

The squashID option creates a complementary ease for scale that perfectly syncs with the bounce impacts.

CustomBounce.create("squashBounce", { strength: 0.6, squash: 3, squashID: "squashBounce-squash" }); gsap.timeline() .to("#squash-ball", { y: 160, ease: "squashBounce", duration: 2 }) .to("#squash-ball", { scaleX: 1.4, scaleY: 0.6, ease: "squashBounce-squash", duration: 2 }, 0);

04 — CustomBounce

Drop Shadow Sync

A synchronized shadow scales inversely as the ball bounces — big shadow when ball is low, small shadow when ball is high. A classic animation trick.

// shadow scaleX driven by the same ease

Both the ball's y position and the shadow's scale use the same "shadowBounce" ease, keeping them perfectly in sync.

CustomBounce.create("shadowBounce", { strength: 0.6, squash: 0 }); gsap.timeline() .to("#shadow-ball", { y: 165, ease: "shadowBounce", duration: 2 }, 0) .to("#shadow-el", { scaleX: 2.5, ease: "shadowBounce", duration: 2 }, 0);
05 — CustomBounce

Choreographed Sequence

Three balls drop at staggered times using a GSAP timeline with position offsets. Each has squash enabled for a satisfying cascading effect.

// staggered drops with squash on each ball

Position offsets in the timeline control when each ball starts, creating a wave-like choreography.

CustomBounce.create("seqBounce", { strength: 0.65, squash: 2, squashID: "seqBounce-squash" }); const tl = gsap.timeline(); [ballA, ballB, ballC].forEach((ball, i) => { tl.to(ball, { y: 185, ease: "seqBounce", duration: 2 }, i * 0.4) .to(ball, { scaleX: 1.4, scaleY: 0.6, ease: "seqBounce-squash", duration: 2 }, i * 0.4); });
