01 — Create

CustomEase.create()

Register a named ease from an SVG-path string. Once registered, reference it by name just like any built-in ease.

CustomEase.create("name", svgPath)

The SVG path string is a normalized cubic-bezier curve (0,0 → 1,1). You can design it in any SVG editor.

CE
CustomEase.create("hop", "M0,0 C0.29,0 0.18,1 0.5,1 0.82,1 0.7,0 1,0"); gsap.to("#box", { x: 220, duration: 1.5, ease: "hop" // use by name });

Create from cubic-bezier CSS values

Paste values directly from browser DevTools or cubic-bezier.com. Format: "x1,y1,x2,y2".

cubic
CustomEase.create("spring", ".17,.67,.83,.67"); gsap.to("#box", { x: 220, duration: 1.2, ease: "spring" });

05 — SlowMo

slow(linearRatio, power, yoyoMode)

SlowMo creates an ease that is fast at start, slow in the middle, then fast again at the end. Great for camera-shutter or highlight-reel effects.

SlowMo parameters

linearRatio = how much of the animation is "slow" (0–1). power = curve steepness.

slow
gsap.to("#sm-box", { x: 220, duration: 2, ease: "slow(0.7, 0.7, false)" // linearRatio=0.7 → 70% of animation is slow middle });
06 — RoughEase

rough({ strength, points, randomize })

RoughEase creates a jittery, hand-drawn feel by randomizing intermediate points. Great for shaking, glitch, and organic motion.

RoughEase strength comparison

Higher strength = more jitter. points sets how many jitter points are used.

rough
gsap.to("#re-box", { x: 220, duration: 2, ease: "rough({ strength: 3, points: 30, randomize: true })" });

Shake effect with RoughEase

Use RoughEase on rotation and x for a realistic camera-shake or error animation.

shake!
gsap.to("#shake-box", { x: "random(-8, 8)", rotation: "random(-6, 6)", duration: 0.6, ease: "rough({ strength:4, points:20 })", yoyo: true, repeat: 1 });
