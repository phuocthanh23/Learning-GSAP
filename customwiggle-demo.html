01 — Basic

Basic Wiggle

Create a named wiggle ease with CustomWiggle.create(), then use its name as the ease in any tween. The box wiggles 6 times on the x-axis.

uniform wiggle · 6 oscillations

A box wiggles left-right 6 times using the "myWiggle" ease. The ease decays symmetrically from the target value.

WIGGLE
CustomWiggle.create("myWiggle", { wiggles: 6, type: "uniform" }); gsap.to(".box", { x: 30, ease: "myWiggle", duration: 1 });

04 — Amplitude

Amplitude Control

Wiggle amplitude is set by the tween property value itself — a larger x value means a bigger wiggle, while the ease shape stays the same.

x:10 · x:30 · x:60 · x:100

All four boxes use the same "anticipate" wiggle ease. The only difference is the target x value in each tween.

x: 10
x: 30
x: 60
x: 100
CustomWiggle.create("ampWiggle", { wiggles: 6, type: "anticipate" }); gsap.to("#box1", { x: 10, ease: "ampWiggle", duration: 1 }); gsap.to("#box2", { x: 30, ease: "ampWiggle", duration: 1 }); gsap.to("#box3", { x: 60, ease: "ampWiggle", duration: 1 }); gsap.to("#box4", { x: 100, ease: "ampWiggle", duration: 1 });
05 — Shake

Shake Effect

High wiggles count with a short duration creates a convincing shake. Great for error states, notifications, and alerts.

bell shake & form error shake

A notification bell shakes to grab attention. A form input shakes when "submitted" with invalid data — a classic UX pattern.

🔔 notification
form field
CustomWiggle.create("shake", { wiggles: 12, type: "uniform" }); gsap.to(bell, { rotation: 15, ease: "shake", duration: 0.5, transformOrigin: "50% 10%" }); gsap.to(input, { x: 8, ease: "shake", duration: 0.5 });
06 — Rotation

Rotation Wiggle

Apply wiggle eases to rotation instead of x/y for a needle wobble or pendulum effect. Great for gauges, indicators, and loading states.

pointer / needle wobble

A needle rotates left-right using the wiggle ease on the rotation property. Transform origin is set to the needle's pivot point.

needle
CustomWiggle.create("needleWiggle", { wiggles: 8, type: "easeOut" }); gsap.to("#needle", { rotation: 15, ease: "needleWiggle", duration: 1.5, transformOrigin: "50% 85%" });
