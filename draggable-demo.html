Mouse and touch drag for any element. Constrain to bounds, rotate, snap, and add momentum with InertiaPlugin.

01 — Basic

Draggable.create()

Make any element draggable with one call. type controls the axis: "x", "y", "x,y", or "rotation".

type: "x,y" — free drag

Drag the box freely in any direction. The position is managed by GSAP transforms.

drag me
Draggable.create("#d-free", { type: "x,y" });

type: "x" — horizontal only

Restrict dragging to a single axis.

← drag →
Draggable.create("#d-x", { type: "x" }); Draggable.create("#d-y", { type: "y" }); // vertical only
02 — Bounds

bounds — constrained drag

Keep elements inside a container with bounds. Pass a selector, element, or {minX, maxX, minY, maxY} object.

bounds: "#container"

The box cannot leave the dashed boundary. Try dragging it to the edge.

bounds area
bounded
Draggable.create("#d-bounded", { type: "x,y", bounds: "#bounds-box", edgeResistance: 0.85 // resistance when hitting edges });

edgeResistance — soft boundary

Values 0–1. At 0 = no resistance (hard stop). At 1 = immovable. Try dragging past the edge.

edge resistance: 0.65
resist
Draggable.create("#d-resist", { type: "x,y", bounds: "#bounds-resist", edgeResistance: 0.65 });
03 — Rotation

type: "rotation" — spin

Drag in a circular motion to rotate an element. Great for dials, knobs, and spin wheels.

04 — Inertia

inertia: true — throw with momentum

InertiaPlugin adds realistic throw/momentum after release. The velocity at release determines how far the element travels.

Throw cards with inertia

Drag a card fast and release — it keeps moving with momentum and slows to a stop.

throw
toss
fling
Draggable.create(".card", { type: "x,y", bounds: "#arena", inertia: true, // requires InertiaPlugin edgeResistance: 0.75 });
05 — Snap

snap — lock to grid on release

Use snap to define discrete positions. The element snaps to the nearest allowed position when released.

snap: { x: gridFn, y: gridFn }

Drag the box across the grid. On release it snaps to the nearest cell center.

snap
const cellW = arena.offsetWidth / 4; const cellH = arena.offsetHeight / 3; Draggable.create("#d-snap", { type: "x,y", bounds: "#snap-arena", snap: { x: v => Math.round(v / cellW) * cellW, y: v => Math.round(v / cellH) * cellH } });

Draggable.create("#d-cb", { type: "x,y", bounds: "#cb-arena", onDragStart() { document.querySelector('#cb-active').textContent = 'true'; }, onDrag() { update(this.x, this.y, this.getVelocity("x"), this.getVelocity("y")); }, onDragEnd() { document.querySelector('#cb-active').textContent = 'false'; } });

Draggable.get() — control instances

Get an existing Draggable instance to enable/disable/kill it programmatically.

toggle me
enabled
const d = Draggable.get("#d-ctrl"); d.disable(); // stops responding to drag d.enable(); // re-activates d.kill(); // completely removes
