Stroke Reveal

Draw a complex decorative path from nothing to full stroke. drawSVG: 0 means the stroke starts invisible; animating to "100%" reveals it entirely.

// gsap.from("#path", { drawSVG: 0 })

03 — Multi-path Sequence

Timeline Draw

A simple house SVG illustration composed of multiple paths. Each segment draws in sequence on a GSAP timeline with staggered timing.

// Staggered multi-path sequence on a timeline

Each structural element of the house draws in one by one — ground, walls, roof, door, window.

const tl = gsap.timeline(); tl.from("#h-ground", { drawSVG: 0, duration: 0.4 }) .from("#h-wall-l", { drawSVG: 0, duration: 0.35 }, "-=0.1") .from("#h-wall-r", { drawSVG: 0, duration: 0.35 }, "-=0.2") .from("#h-roof-l", { drawSVG: 0, duration: 0.35 }, "-=0.1") .from("#h-roof-r", { drawSVG: 0, duration: 0.35 }, "-=0.2") .from("#h-door", { drawSVG: 0, duration: 0.4 });
04 — Handwriting Reveal

Signature Draw

A cursive-style SVG path simulating handwriting. Animating with ease: "none" keeps the drawing speed constant, matching how a pen actually moves.

// ease: "none" for realistic pen drawing

The signature path is revealed at a steady rate — no ease in or out — for an authentic feel.

const tl = gsap.timeline(); tl.from("#hw-g", { drawSVG: 0, duration: 1.0, ease: "none" }) .from("#hw-s", { drawSVG: 0, duration: 0.8, ease: "none" }, "-=0.1") .from("#hw-a", { drawSVG: 0, duration: 0.9, ease: "none" }, "-=0.1") .from("#hw-p", { drawSVG: 0, duration: 0.9, ease: "none" }, "-=0.1") .from("#hw-line", { drawSVG: 0, duration: 1.2, ease: "power2.out" }, "-=0.2");
05 — Draw & Erase Loop

Infinite Loop

Continuous draw → erase → repeat using yoyo: true, repeat: -1. The stroke fills, holds, then retraces itself back to nothing.

// yoyo: true, repeat: -1 for perpetual draw/erase

A decorative star and circle constellation that endlessly draws and undraws itself.

gsap.fromTo("#loop-circle", { drawSVG: "0% 0%" }, { drawSVG: "0% 100%", duration: 2, ease: "power1.inOut", yoyo: true, repeat: -1, repeatDelay: 0.4 } ); gsap.fromTo("#loop-star", { drawSVG: "0% 0%" }, { drawSVG: "0% 100%", duration: 2, ease: "power2.inOut", yoyo: true, repeat: -1, delay: 0.3 } );
