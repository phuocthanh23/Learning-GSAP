SlowMo, RoughEase, SteppedEase, ExpoScaleEase — specialty easing functions that go far beyond the standard library.

01 — SlowMo

SlowMo Ease

Moves fast at start and end but slows dramatically in the middle. Perfect for cinematic text reveals and dramatic entrances.

// SlowMo.ease.config(linearRatio, power, yoyoMode)

Adjust the sliders to reshape the ease. The curve preview updates live.

0.7
gsap.to("#ball", { x: trackWidth, duration: 2, ease: SlowMo.ease.config(0.7, 0.7, false) });
02 — RoughEase

Rough Ease

Adds random "roughness" to a motion path. Great for simulating shaking, jitter, glitch, or organic movement.

// RoughEase with configurable strength & template

The ball shakes with a rough path. Randomize to generate a new noise pattern.

1.0
gsap.to("#ball", { x: trackWidth, duration: 2, ease: "rough({strength:1, points:20, template:power2, randomize:true, clamp:false})" });
03 — SteppedEase

Stepped Ease

Moves in discrete, quantised jumps instead of continuous motion. Ideal for sprite animations or retro-style movement.

// SteppedEase.config(steps) vs linear

Select a step count to see both SteppedEase (amber) and linear (purple) side by side.

SteppedEase
linear
gsap.to("#ball", { x: trackWidth, duration: 1.5, ease: SteppedEase.config(8) });
04 — ExpoScaleEase

ExpoScale Ease

Designed for scale animations that span very different magnitudes (e.g. 0.5 to 100). It corrects the perceptual "stall" in mid-scale transitions.

// ExpoScaleEase.config(start, end)

The box scales from 0.1 to 1 using ExpoScaleEase (left) vs. a standard power3 ease (right). Notice how the expo version feels more even.

ExpoScale

gsap.to("#box", { scale: 1, duration: 2, ease: ExpoScaleEase.config(0.1, 1) });
