01 — Concept

First, Last, Invert, Play

FLIP records element positions before and after a DOM change, then runs the delta in reverse — making it look like elements moved smoothly.

The 3-step pattern

1. Capture state → 2. Change DOM (class, order, parent) → 3. Flip.from(state) animates from old → new.

FLIP
const state = Flip.getState("#box"); // 1. capture el.classList.toggle("moved"); // 2. change layout Flip.from(state, { // 3. animate duration: 0.6, ease: "power2.inOut" });

05 — Add / Remove

Animate items entering and leaving

Use Flip.from() with onEnter and onLeave callbacks to animate new items in and removed items out, while existing items shuffle smoothly.

Click item to remove · Add button adds new

Removed items fade out. Added items fly in from below. All others move smoothly to fill the gap.

const state = Flip.getState(".ar-item"); el.remove(); // remove from DOM first Flip.from(state, { duration: 0.5, ease: "power2.inOut", onLeave: els => gsap.to(els, { opacity:0, scale:0.5, duration:0.3 }) });
06 — Options

Flip.from() options

Compare absolute: false vs true, scale mode, and different eases.

absolute: true — prevents layout collapse

When true, elements are set to position:absolute during the flip so they don't affect layout of siblings mid-animation.
