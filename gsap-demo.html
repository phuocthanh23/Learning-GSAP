01 — Tweens

gsap.to()

Animates from the current state TO the values you define. The most-used tween method.

gsap.to() — animate to values

Box moves to x:200 with a bounce ease.

to()
gsap.to("#to-box", { x: 200, duration: 1, ease: "bounce.out" });

gsap.from() — animate from values

Box enters FROM below and invisible — great for entrance animations.

from()
gsap.from("#from-box", { y: 60, opacity: 0, duration: 0.8, ease: "back.out(1.7)" });
02 — fromTo & set

gsap.fromTo() & gsap.set()

Full control over start and end states, or instant property assignment.

gsap.fromTo() — explicit start & end

Defines BOTH the starting and ending values precisely.

fromTo
gsap.fromTo("#fromto-box", { x: -150, rotation: -90, opacity: 0 }, { x: 150, rotation: 90, opacity: 1, duration: 1.2, ease: "power3.inOut" } );

gsap.set() — instant property assignment

No animation — sets values immediately. A zero-duration tween.

set()
gsap.set("#set-box", { opacity: 1, borderRadius: "10px", scale: 1.3, rotation: 45 });
03 — Timeline

gsap.timeline()

Chain tweens with precise timing. Control the whole sequence as one unit. Add labels, callbacks, and nested timelines.

gsap.timeline() with position parameter

Four boxes animate in sequence with overlaps. The timeline progress bar shows playback.

C

const tl = gsap.timeline({ onUpdate: updateBar }); tl.to("#tl-a", { opacity:1, y:0, duration:0.6 }) .addLabel("mid") .to("#tl-b", { opacity:1, y:0, duration:0.6 }, "-=0.3") .to("#tl-c", { opacity:1, y:0, duration:0.6 }, "-=0.3") .to("#tl-d", { opacity:1, y:0, duration:0.6 }, "-=0.3") .call(() => log("done!"));

tl.add() and tl.addLabel()

Insert tweens or labels at specific times. Seek to labels by name.

add()
tl.addLabel("step1", 0).addLabel("step2", 1); tl.to("#add-box", { opacity:1, x:100 }, "step1"); tl.to("#add-box", { rotation:360, scale:1.5 }, "step2");

tl.call() — callback at timeline position

A callback fires at exactly 1 second into the timeline.

call()
tl.to("#call-box", { x:100, duration:2 }) .call(() => el.textContent = "✓ callback fired!", null, 1);
04 — Playback Control

play / pause / seek / reverse / restart

Every animation is controllable. Pause, reverse, scrub the playhead, adjust speed.

play() / pause() / resume() / reverse() / restart()

Full transport controls on a single looping tween.

ctrl
ready
tween.play(); tween.pause(); tween.resume(); tween.reverse(); tween.restart();

seek() — jump to any time

Drag to scrub through the animation timeline.

seek
0.0s
tween.pause(); tween.seek(1.5); // jump to 1.5 seconds

timeScale() — control speed

1 = normal, 2 = double, 0.5 = slow-mo, -1 = reverse.

speed
1.0×
tween.timeScale(2); // 2× speed tween.timeScale(0.5); // slow motion tween.timeScale(-1); // reverse

progress() — get or set progress

0 = start, 0.5 = midpoint, 1 = end. Drag to scrub by progress fraction.

prog
0.00
tween.progress(0.5); // jump to 50% console.log(tween.progress()); // get current

kill() & killTweensOf()

Destroy a tween mid-animation and free its memory. Click "run" then "kill".

kill()
idle
killTween = gsap.to("#kill-box", { x:200, duration:4 }); killTween.kill(); // stops & frees memory gsap.killTweensOf("#kill-box"); // kill all on target
05 — Stagger

stagger

Animate multiple targets with incremental delays. Supports from-center, grid, ease, and amount configs.

stagger — number

Simple stagger: each element starts 0.08s after the previous.

gsap.to(".sg-item", { opacity:1, scale:1, duration:0.5, stagger:0.08, ease:"back.out" });

stagger — from: "center"

Animation radiates outward from the center element.

gsap.to(".sg-item", { opacity:1, scale:1, duration:0.6, stagger: { each:0.08, from:"center", ease:"power2.inOut" } });

07 — Config & Global

registerPlugin / defaults / config / ticker

Global GSAP settings, plugin registration, the animation ticker, and master timeline control.

gsap.defaults()

Sets a global default ease and duration. All tweens below inherit them unless overridden.

default
gsap.defaults({ ease: "elastic.out(1,0.3)", duration: 1.5 }); gsap.to("#def-box", { x: 200 }); // uses defaults

gsap.registerEase()

Register a custom easing function by name and use it like any built-in ease.

custom
gsap.registerEase("staircase", p => Math.floor(p * 5) / 5); gsap.to("#ease-box", { x: 200, ease: "staircase", duration: 1.5 });

gsap.ticker

Add a function to GSAP's rAF loop. The counter below increments every frame.

0
frames elapsed
gsap.ticker.add((time, delta) => { frameCount++; });

gsap.globalTimeline

Control every single animation at once — pause everything or slow the whole world.

1.0×
gsap.globalTimeline.pause(); gsap.globalTimeline.resume(); gsap.globalTimeline.timeScale(0.5);

gsap.registerPlugin()

Required when using plugins with bundlers to prevent tree-shaking. Run before any plugin tween.

import { ScrollTrigger, Flip, TextPlugin } from "gsap/all"; gsap.registerPlugin(ScrollTrigger, Flip, TextPlugin); // Now you can use these plugins safely in your build

gsap.config()

Global GSAP configuration — suppress warnings, set default units, control autoSleep.

gsap.config({ nullTargetWarn: false, // suppress missing target warnings units: { x: "vw", y: "vh" }, // default units per property autoSleep: 60 // pause ticker after 60s idle });

gsap.exportRoot()

Exports all current tweens into a new timeline — new tweens won't be affected.

export
gsap.to("#er-box", { x: 200, duration: 3 }); const master = gsap.exportRoot(); master.timeScale(0.2); // slows only existing tweens
08 — Context & matchMedia

gsap.context() & gsap.matchMedia()

Scope animations for cleanup (React/Vue) and adapt to media queries responsively.

gsap.context() — scoped cleanup

Groups all animations inside it. Call ctx.revert() to undo them all — essential in React useEffect cleanup.

ctx-A
ctx-B
ctx-C
idle — not mounted
const ctx = gsap.context(() => { gsap.to("#ctx-a", { opacity:1, x:60 }); gsap.to("#ctx-b", { opacity:1, x:60, delay:0.2 }); gsap.to("#ctx-c", { opacity:1, x:60, delay:0.4 }); }); // In React: return () => ctx.revert(); ctx.revert(); // reverts ALL animations inside context

gsap.matchMedia() — responsive animations

Different animations run based on the current viewport width. Resize your window to see the active breakpoint change.

mm()
≥ 768px — desktop animation active
< 768px — mobile animation active
const mm = gsap.matchMedia(); mm.add("(min-width: 768px)", () => { gsap.to("#mm-box", { x:200, rotation:360, duration:1 }); }); mm.add("(max-width: 767px)", () => { gsap.to("#mm-box", { y:80, scale:1.5, duration:1 }); });
