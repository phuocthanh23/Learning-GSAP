01 — InertiaPlugin

Draggable with Inertia

Drag the box and release it — it glides to a stop with natural momentum. InertiaPlugin automatically tracks velocity and decelerates smoothly.

// Draggable.create with inertia: true

Drag fast for long glide, slow for short. The box is bounded to the stage so it never escapes.

drag me
← throw it!
Draggable.create("#drag-box", { type: "x,y", bounds: "#stage-drag", inertia: true });
02 — InertiaPlugin

Snap to Grid

After releasing the box, it decelerates and snaps to the nearest 80px grid intersection. The grid is visible as a reference.

// snap function rounds to nearest grid cell

Throw the box across the grid — it will always land on a grid point. Useful for puzzle games, layout tools, or tile-based UIs.

snap
Draggable.create("#snap-box", { type: "x,y", bounds: "#stage-snap", inertia: true, snap: { x: v => Math.round(v / 80) * 80, y: v => Math.round(v / 80) * 80 } });
03 — InertiaPlugin

Velocity Tracking

Track a moving element's live velocity with InertiaPlugin.track(), then use "auto" to continue that exact velocity when handing off control.

// InertiaPlugin.track() then inertia: { x: "auto" }

The ball bounces back and forth. Click "release!" to let InertiaPlugin capture its current velocity and coast naturally to a stop.

velocity: 0 px/s
InertiaPlugin.track(ball, "x"); // ... ball animates back and forth ... // on release: gsap.to(ball, { inertia: { x: "auto", min: 0, max: stageWidth } });
04 — InertiaPlugin

Resistance Comparison

Three balls launched with identical velocity (1000 px/s) but different resistance values. Higher resistance = stops sooner.

// resistance: 50 | 200 | 800

Resistance controls deceleration force. Low = slides like ice. High = stops like sand. Watch how far each ball travels.

resistance: 50 (slides far)
resistance: 200 (medium)
resistance: 800 (stops fast)
gsap.to("#resist-a", { inertia: { x: { velocity: 1000, resistance: 50 } } }); gsap.to("#resist-b", { inertia: { x: { velocity: 1000, resistance: 200 } } }); gsap.to("#resist-c", { inertia: { x: { velocity: 1000, resistance: 800 } } });
05 — InertiaPlugin

Min / Max Constraints

Inertia can be bounded with min and max values. The element glides but clamps within the specified range.

// inertia: { x: { velocity, min: 0, max: 400 } }

Click "throw left" or "throw right" to launch the handle with a velocity. It glides and stops within the track bounds — never escaping.

slide
min: 0
max: 400
gsap.to("#minmax-handle", { inertia: { x: { velocity: 800, min: 0, max: 400 } } });
06 — InertiaPlugin

Rotation Inertia

A dial you can spin with your mouse. After releasing, it continues rotating and gradually slows to a stop — like a real physical dial.

// Draggable type: "rotation" with inertia: true

Grab the dial and spin it quickly. Momentum carries it further after release, decelerating naturally. Drag slowly for a gentle stop.

rotation: 0°
Draggable.create("#dial", { type: "rotation", inertia: true, onDrag: function() { label.textContent = `rotation: ${Math.round(this.rotation)}°`; } });
