Seamlessly morph SVG paths, polygons, and shapes with GSAP's MorphSVGPlugin. Animate the d attribute with zero hassle.

01 — Basic

Shape to Shape

MorphSVGPlugin converts primitives to paths automatically, then animates between them. Here a circle morphs into a 5-point star.

circle → star → circle

Both shapes are converted to paths via MorphSVGPlugin.convertToPath(), then morphed with morphSVG.

gsap.to("#shape", { morphSVG: "#starTarget", duration: 1, ease: "power2.inOut" });
02 — Icons

Icon Morphs

Morph between UI icons for smooth, expressive state transitions. Play/Pause and Hamburger/Close are classic use cases.

play ▶ → pause ⏸

Morph a play triangle path into two pause bars using morphSVG: { shape: "#pausePath" }.

hamburger ☰ → close ✕

Three line paths morph: top line rotates to one diagonal, bottom rotates to the other, middle fades out.

03 — shapeIndex

shapeIndex Control

shapeIndex controls where the morph starts on the target path. A bad index causes twisting; a good index gives a clean morph.

default vs optimized shapeIndex

Left: shapeIndex: 0 (default — may twist). Right: shapeIndex: 4 (optimized — clean path). Watch the difference in rotation.

shapeIndex: 0 (default)
shapeIndex: 4 (optimized)
gsap.to("#shape", { morphSVG: { shape: "#target", shapeIndex: 4 }, duration: 1.5, ease: "power2.inOut" });
04 — Type

Linear vs Rotational

type: "linear" interpolates points directly. type: "rotational" decomposes each point's angle and magnitude for smoother organic morphs.

same morph, different type

Both morph from the same blob to a star simultaneously. Notice how rotational feels more fluid and organic.

type: "linear"
type: "rotational"
gsap.to("#blob", { morphSVG: { shape: "#star", type: "rotational" }, duration: 1.5, ease: "power2.inOut" });
05 — Loop

Continuous Morph Loop

Chain multiple morphs in a GSAP timeline with repeat: -1 for an infinite organic animation loop through 4 blob shapes.

blob1 → blob2 → blob3 → blob4 → blob1

A timeline morphs through four distinct blobs endlessly. Each step uses ease: "sine.inOut" for organic motion.

gsap.timeline({ repeat: -1, yoyo: false }) .to("#shape", { morphSVG: "#blob2", duration: 1.5, ease: "sine.inOut" }) .to("#shape", { morphSVG: "#blob3", duration: 1.5, ease: "sine.inOut" }) .to("#shape", { morphSVG: "#blob4", duration: 1.5, ease: "sine.inOut" }) .to("#shape", { morphSVG: "#blob1", duration: 1.5, ease: "sine.inOut" });
