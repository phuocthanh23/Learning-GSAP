Animate any element along an SVG path. Align to path, auto-rotate with the curve, and run multiple objects with stagger.

01 — Basic

motionPath: { path }

Pass any SVG path element or selector. GSAP moves the target along the path over the duration.

Animate along a wave path

The dot follows the SVG path. The path is visible as a guide — you can hide it in production.

gsap.registerPlugin(MotionPathPlugin); gsap.to("#dot", { duration: 3, ease: "none", motionPath: { path: "#wave-path", align: "#wave-path", alignOrigin: [0.5, 0.5] } });
02 — autoRotate

autoRotate — follow the curve

autoRotate: true makes the element rotate to face its direction of travel. Use a number to add a rotation offset (e.g. 90 for a side-facing element).

Rocket following a looping path

With autoRotate, the rocket faces the direction it's moving at all times.

🚀
gsap.to("#rocket", { duration: 5, repeat: -1, ease: "none", motionPath: { path: "#loop-path", align: "#loop-path", alignOrigin: [0.5, 0.5], autoRotate: true // rotate to face direction of travel } });
03 — Align

align + alignOrigin

align registers the element's position relative to the path in the SVG coordinate system. alignOrigin [x,y] controls which point of the element tracks the path (0,0 = top-left; 0.5,0.5 = center; 1,1 = bottom-right).

alignOrigin comparison

Three dots on the same circular path with different alignOrigin values.

[0.5,0.5] center
[0,0] top-left
[1,1] bottom-right
gsap.to("#dot", { motionPath: { path: "#circle-path", align: "#circle-path", alignOrigin: [0.5, 0.5] }, duration: 3, repeat: -1, ease: "none" }); // alignOrigin[0] = x (0=left, 1=right) // alignOrigin[1] = y (0=top, 1=bottom)
04 — Multiple Objects

Staggered convoy

Animate multiple objects on the same path with stagger. Each starts at a different time, creating a convoy effect.

Stagger on a shared path

Five dots animate along the same path with 0.3s stagger. All share one tween call.

gsap.to(["#c1","#c2","#c3","#c4","#c5"], { duration: 3, ease: "power1.inOut", stagger: 0.3, // each starts 0.3s after the previous motionPath: { path: "#convoy-path", align: "#convoy-path", alignOrigin: [0.5, 0.5], autoRotate: true } });
05 — Loop

repeat: -1 — infinite loop

Set repeat: -1 with ease: "none" for a smooth perpetual loop. The path must close (end at start) for seamless looping.

Satellite orbit — infinite loop

The satellite loops the elliptical orbit forever. timeScale slider controls speed.

🛸
1.0×
const tween = gsap.to("#satellite", { duration: 6, repeat: -1, ease: "none", motionPath: { path: "#orbit-path-el", align: "#orbit-path-el", alignOrigin: [0.5, 0.5], autoRotate: false } }); tween.timeScale(2); // speed up
06 — Raw Path Data

path: "M…" — inline path string

Instead of an SVG element reference, pass raw SVG path data as a string. Useful for programmatically generated paths.

Path data string — no SVG element needed

MotionPath accepts the path d attribute value directly as a string. The element doesn't need to be in the DOM.

gsap.to("#dot", { duration: 3, repeat: -1, ease: "none", motionPath: { path: "M 100,100 C 200,20 300,180 400,100 S 600,20 700,100", // raw path data string — no SVG element required autoRotate: true } });
