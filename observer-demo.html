03 — Slide Navigation

Full-section slide navigation

Observer is ideal for hijacking scroll to drive a slide-by-slide experience. Each gesture advances exactly one slide, regardless of scroll speed.

Scroll / swipe to navigate slides

Each up/down gesture transitions one slide. Animations lock until the transition finishes.

05 — Tolerance

tolerance — gesture threshold

Tolerance sets how many pixels of movement must occur before a direction is fired. Higher = less sensitive. Useful to prevent accidental triggers.

06 — Control

enable / disable / kill

Observer instances can be paused and re-enabled at any time. Use this to lock interactions during animations.

Observer.create() returns a controllable instance

Toggle the observer on and off. Notice the event log stops when disabled.

observer: enabled
—
const obs = Observer.create({ target: "#ctrl-zone", ... }); obs.disable(); // pauses — no callbacks fire obs.enable(); // re-activates obs.kill(); // removes completely
