Control Pixi.js DisplayObjects with GSAP's full easing and timeline power. Animate tint, blur, scale, rotation, and alpha seamlessly.

01 — Setup

Setup & Registration

Register PixiPlugin with both GSAP and Pixi.js. Then animate any DisplayObject property using the pixi: {} tween vars object.

basic x, y, alpha animation

A rectangle and circle animate position and alpha on the Pixi stage using GSAP tweens.

gsap.registerPlugin(PixiPlugin); PixiPlugin.registerPIXI(PIXI); const app = new PIXI.Application({ width: 600, height: 220, backgroundColor: 0x1a1a26, antialias: true }); gsap.to(sprite, { pixi: { x: 200, y: 100, alpha: 0.5 }, duration: 1, ease: "power2.out" });
02 — Tint

Color Tint Animation

Animate the tint property of Pixi DisplayObjects using hex color values. GSAP interpolates colors smoothly between states.

cycling tint colors

Three shapes cycle through a palette of tint colors via a GSAP timeline. Tint values are hex numbers like 0xffb830.

gsap.to(shape, { pixi: { tint: 0xffb830 }, duration: 0.8, ease: "power1.inOut" }); // Chain colors in a timeline gsap.timeline() .to(shape, { pixi: { tint: 0xff5c8a }, duration: 0.6 }) .to(shape, { pixi: { tint: 0x00e5c0 }, duration: 0.6 }) .to(shape, { pixi: { tint: 0x7850ff }, duration: 0.6 });
03 — Blur

Blur Filter

Animate the blur filter strength with pixi: { blur: 20 }. The object must have a PIXI.BlurFilter already applied before tweening.

focus / unfocus

A circle with a BlurFilter applied animates between crisp focus and heavy blur using GSAP's pixi property.

const blurFilter = new PIXI.BlurFilter(); circle.filters = [blurFilter]; // Unfocus gsap.to(circle, { pixi: { blur: 20 }, duration: 0.8, ease: "power2.inOut" }); // Focus gsap.to(circle, { pixi: { blur: 0 }, duration: 0.8, ease: "power2.out" });
04 — Scale

Scale & Rotation

Animate scaleX, scaleY, and rotation through the pixi property. Perfect for squash-and-stretch and spin effects.

squash, stretch & spin

A Pixi Graphics rectangle demonstrates squash-and-stretch by animating scaleX and scaleY independently, plus a full rotation.

gsap.to(rect, { pixi: { scaleX: 2, scaleY: 0.5 }, duration: 0.6, ease: "back.out(1.7)" }); gsap.to(rect, { pixi: { rotation: Math.PI * 2 }, duration: 1, ease: "power2.inOut" });
05 — Timeline

GSAP Timeline with Pixi

Orchestrate multiple Pixi objects with a GSAP timeline — stagger positions, tint changes, alpha fades, and scale pulses all in sequence.

multi-object choreography

Five colored circles move around the stage with staggered timing, tint shifts, alpha fades, and scale pulses — all driven by one GSAP timeline.

const tl = gsap.timeline(); tl.to(circles, { pixi: { x: 200, y: 80, tint: 0xffb830 }, duration: 0.8, stagger: 0.12, ease: "power2.out" }) .to(circles, { pixi: { alpha: 0.3, scaleX: 1.5, scaleY: 1.5 }, duration: 0.5, stagger: 0.08 }, "-=0.3");
