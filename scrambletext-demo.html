// chars: "upperCase" — uppercase scramble

Click to scramble

03 — ScrambleText

revealDelay Effect

revealDelay controls how long a character scrambles before showing its real value. Low = resolves early, high = scrambles longer.

// revealDelay: 0 vs revealDelay: 0.8

Both elements receive the same text at the same time. The difference in revealDelay dramatically changes how the effect feels.

revealDelay: 0
Resolve quickly
revealDelay: 0.8
Scramble longer
gsap.to("#reveal-fast", { duration: 1.5, scrambleText: { text: "Resolved fast", chars: "upperCase", revealDelay: 0 } }); gsap.to("#reveal-slow", { duration: 1.5, scrambleText: { text: "Scrambled long", chars: "upperCase", revealDelay: 0.8 } });
04 — ScrambleText

Speed Control

speed (0–1) controls how rapidly the scramble characters change each frame. Low speed = sluggish, high speed = rapid flickering.

// drag slider to set speed, then scramble

Adjust the speed before each scramble to hear the difference in energy. Very low values create a sluggish, eerie feel.

Adjust speed and fire
0.5
gsap.to("#speed-text", { duration: 1.5, scrambleText: { text: "Speed matters", chars: "upperCase", speed: 0.5 // ← drag slider to change } });
05 — ScrambleText

newClass Highlight

newClass adds a CSS class to each character the moment it resolves from scrambling to its real value — perfect for color highlights on reveal.

// newClass: "new-char" — highlights chars on reveal

As each character resolves, it gets class="new-char" briefly, turning teal. Watch characters light up as they snap into place.

Reveal me character by character
gsap.to("#newclass-text", { duration: 2, scrambleText: { text: "Characters light up as they resolve", chars: "upperCase", newClass: "new-char", speed: 0.4 } });
06 — ScrambleText

Infinite Scramble Cycle

A GSAP timeline with repeat: -1 continuously cycles through messages, each scrambling into the next with a pause between.

// timeline repeat: -1, cycling 4 messages

The timeline chains ScrambleText tweens with pauses, looping forever. Stop/start the cycle with the buttons.

SYSTEM READY
const messages = ["SYSTEM READY", "LOADING DATA", "ACCESS GRANTED", "INITIALIZING"]; const tl = gsap.timeline({ repeat: -1 }); messages.forEach(msg => { tl.to("#loop-text", { duration: 1.2, scrambleText: { text: msg, chars: "upperCase", speed: 0.5 } }).to({}, { duration: 1.2 }); // pause });
