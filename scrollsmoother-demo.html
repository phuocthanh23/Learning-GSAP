01 — Setup

Required DOM structure

ScrollSmoother replaces native scroll with a transform-based equivalent. The wrapper clips; the content moves. Everything inside #smooth-content is smoothed.

HTML structure

The wrapper is fixed and full-screen. The content moves via CSS transform driven by GSAP.

<!-- Required structure --> <div id="smooth-wrapper"> ← fixed, overflow:hidden <div id="smooth-content"> ← moves via transform <!-- all page content here --> </div> </div> gsap.registerPlugin(ScrollTrigger, ScrollSmoother); const smoother = ScrollSmoother.create({ wrapper: "#smooth-wrapper", content: "#smooth-content", smooth: 1.5, // seconds to catch up effects: true // enable data-speed / data-lag attributes });

02 — Smooth

smooth — inertia duration

The smooth value is the number of seconds the content takes to "catch up" to the native scroll. Higher = more inertia, dreamier feel.

smooth: 1.5 is active on this page

Scroll fast and notice how the content eases to a stop after your finger/wheel releases. This is the effect of smooth: 1.5.

1.5s
current smooth value
ScrollSmoother.create({ smooth: 1.5 // 0 = no smoothing, 1 = 1s lag, 4 = very dreamy }); // Change at runtime: smoother.smooth(2);
03 — Speed Effects

data-speed — parallax per element

Add data-speed to any element inside #smooth-content. 1 = normal, <1 = slower (floats back), >1 = faster (races ahead).

data-speed — scroll at different rates

Each card moves at a different speed relative to the scroll. Scroll through this section slowly.

04 — Lag

data-lag — trailing inertia per element

data-lag adds an individual momentum delay to an element. Different from smooth — lag applies on top of the global smooth, creating a trailing "jelly" effect.

data-lag — boxes trail at different rates

Scroll quickly and watch how each box lags behind by a different amount.

<div data-lag="0">no extra lag</div> <div data-lag="0.4">0.4s trailing lag</div> <div data-lag="0.8">0.8s trailing lag</div> // Lag = extra smoothing on top of global smooth

07 — Control

smoother.scrollTo() / paused() / kill()

Control the smoother programmatically: scroll to any position, element, or pause/resume entirely.

smoother.scrollTo() — programmatic smooth scroll

Scroll to any position or element with the smooth motion active.

smoother.scrollTo("#section", true); // smooth scroll to element smoother.scrollTo(1000, true); // scroll to pixel position

paused() — freeze the smoother

Pause the smoother to lock scroll position (e.g. during a modal or menu open).

running
smoother.paused(true); // freeze scroll smoother.paused(false); // resume smoother.paused(); // getter — returns current state

ScrollSmoother.get() — access the instance

Retrieve the singleton smoother instance from anywhere in your code.

const smoother = ScrollSmoother.get(); smoother.smooth(2); // change smooth at runtime smoother.effects(".slow"); // re-apply effects to new elements smoother.kill(); // removes ScrollSmoother entirely
