01 — Basic Trigger

scrollTrigger: { trigger }

Attach a ScrollTrigger to any tween via the scrollTrigger property. Control when it fires with start/end and what it does with toggleActions.

toggleActions — play / reverse

The box animates in when it enters the viewport and reverses when it leaves. Scroll back up to see it reset.

enter
waiting…
gsap.from("#basic-box", { x: -120, opacity: 0, scale: 0.5, rotation: -45, duration: 0.8, ease: "back.out(1.7)", scrollTrigger: { trigger: "#basic-box", start: "top 85%", // top of box hits 85% down viewport end: "bottom 20%", toggleActions: "play none none reverse" } });

once: true — fire and forget

The ScrollTrigger kills itself after the animation plays once. Scrolling back will not reset it.

once
waiting…
gsap.from("#once-box", { opacity: 0, scale: 0, rotation: 180, duration: 1, ease: "elastic.out(1,0.5)", scrollTrigger: { trigger: "#once-box", start: "top 85%", once: true // kills the ScrollTrigger after it fires } });
02 — Scrub

scrub — scroll-linked animation

Tie animation progress directly to scroll position. scrub: true = instant sync; scrub: number = seconds of lag/smoothing.

scrub: true — direct link

The box moves and rotates exactly as you scroll through this section. Progress bar mirrors it.

scrub
0% scroll progress
gsap.to("#scrub-box-1", { x: 200, rotation: 360, scale: 1.4, ease: "none", // use none for predictable scrub scrollTrigger: { trigger: "#scrub-trigger-1", start: "top 70%", end: "bottom 30%", scrub: true, onUpdate: self => updateScrubUI(1, self.progress) } });

scrub: 1 — smoothed (1 second lag)

A 1-second smoothing lag means the animation catches up after you stop scrolling. Try fast vs. slow scrolling.

lag
0% animation progress (lags behind)
gsap.to("#scrub-box-2", { x: 200, borderRadius: "50%", backgroundColor: "#ff5c8a", ease: "none", scrollTrigger: { trigger: "#scrub-trigger-2", start: "top 70%", end: "bottom 30%", scrub: 1 // 1 second to catch up } });

03 — Pin

pin — stick while scrolling

Pin an element in place while a scroll range is active. Combine with scrub to build narrative scroll experiences.

pin: true with scrub

The pinned panel stays fixed while you scroll through a 500px range. The animation inside scrubs with scroll.

06 — toggleClass

toggleClass — CSS-driven state

Add/remove a CSS class when the ScrollTrigger is active. No JS animation required — great for style changes.

09 — Snap

snap — jump to waypoints

After scrolling, snap the playhead to the nearest defined progress value. Works like scroll-snap but for any animation.

snap: 0.25 — four equal steps

After you stop scrolling, the animation snaps to the nearest 25% increment (0, 0.25, 0.5, 0.75, 1).

snap
step 0
gsap.to("#snap-box", { x: 220, rotation: 360, ease: "none", scrollTrigger: { trigger: "#snap-trigger", start: "top 70%", end: "+=600", scrub: 0.5, snap: { snapTo: 0.25, // snap to 0, 0.25, 0.5, 0.75, 1 duration: 0.4, // time to animate snap ease: "power1.inOut" }, onUpdate: self => updateSnapUI(self.progress) } });
10 — Standalone

ScrollTrigger.create() — no animation

A ScrollTrigger without an animation — pure event detection. Use callbacks to run any custom logic when entering/leaving scroll zones.

ScrollTrigger.create() — scroll zone detector

No GSAP animation is attached. The trigger just fires callbacks and updates the UI as you scroll through it.

ScrollTrigger.create({ trigger: "#standalone-trigger", start: "top 75%", end: "bottom 25%", onEnter: () => setActive(true), onLeave: () => setActive(false), onEnterBack: () => setActive(true), onLeaveBack: () => setActive(false), onUpdate: self => updateStandalone(self.progress) });

ScrollTrigger.getAll() / kill

Inspect all living ScrollTrigger instances and kill them all at once. Essential for SPA cleanup.

— instances
active ScrollTrigger instances
ScrollTrigger.getAll(); // array of all instances ScrollTrigger.getAll().length; // count ScrollTrigger.getById("my-id"); // find by id ScrollTrigger.refresh(); // recalculate all positions ScrollTrigger.getAll().forEach(t => t.kill()); // kill all
