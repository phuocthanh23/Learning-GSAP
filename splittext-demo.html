01 — Characters

Animate Characters

Split a heading into individual chars. Each character becomes a wrapper element you can tween independently with staggered timing.

// type: "chars" · stagger + rotationX

Characters tumble in from above using a 3D rotation on the X axis. "Revert" restores the original DOM markup.

Animate Everything
const split = SplitText.create("#chars-target", { type: "words,chars" }); gsap.from(split.chars, { opacity: 0, y: 40, rotationX: -90, stagger: 0.03, duration: 0.5, ease: "back.out(1.7)" }); // Restore original markup: split.revert();

04 — autoSplit

autoSplit + onSplit

autoSplit: true automatically re-splits when the element width changes (e.g. window resize). Returning the animation from onSplit lets SplitText sync progress and clean up on each re-split.

// autoSplit + onSplit — resize-safe animation

This heading re-splits on every resize. The animation restarts automatically with correct line counts each time. Try resizing the window.

Responsive type animation that adapts to every screen width automatically.
autoSplit: true — this split re-fires and re-animates on window resize.
The onSplit callback returns the tween so SplitText can clean up old animations.
SplitText.create("#autosplit-target", { type: "lines", mask: "lines", autoSplit: true, onSplit(self) { return gsap.from(self.lines, { yPercent: 110, opacity: 0, stagger: 0.12, duration: 0.7, ease: "power3.out" }); } });

06 — Classes & propIndex

charsClass & propIndex

charsClass: "char++" adds incremented class names (char1, char2…) to each character element. propIndex: true injects CSS custom properties (--char: 1) for CSS-driven stagger effects.

// charsClass: "char++" for CSS-targeted styling

The split adds char1…charN classes. CSS selectors target every 4th char with different accent colors. No JS needed for the colors.

Color Chars
const split = SplitText.create("#class-target", { type: "chars", charsClass: "char++" // → char1, char2, char3 … }); /* CSS then targets every 4th starting at n: .char1, .char5, .char9 { color: var(--accent4); } .char2, .char6, .char10 { color: var(--accent2); } .char3, .char7, .char11 { color: var(--accent3); } .char4, .char8, .char12 { color: var(--accent); } */ gsap.from(split.chars, { opacity: 0, scale: 0.3, rotation: -30, stagger: 0.05, duration: 0.5, ease: "back.out(2)" });

// propIndex: true — CSS custom property per char

With propIndex: true, each char element gets a --char: N CSS variable. Use calc() in CSS to derive staggered hue, opacity, or transform.

Index Colors
const split = SplitText.create("#propindex-target", { type: "chars", propIndex: true // adds --char: N on each element }); /* CSS uses hsl() with calc() on the var: .char-pi { color: hsl(calc(var(--char, 0) * 22deg), 90%, 70%); } */ gsap.from(split.chars, { opacity: 0, y: 30, stagger: 0.04, duration: 0.5, ease: "power3.out" });
