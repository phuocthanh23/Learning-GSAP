Animate text content character-by-character or word-by-word. Build typewriter effects, sequenced reveals, and live text transitions.

01 — Basic

gsap.to(el, { text: "…" })

Set the text property to any string. GSAP replaces the element's innerText one character at a time over the duration.

Basic text replacement

The element's content animates character-by-character from the current value to the new one.

Hello, World!
gsap.registerPlugin(TextPlugin); gsap.to("#basic-text", { duration: 1.5, text: "Animated with TextPlugin!", ease: "none" });

text: { value } — object form

The object form gives you extra control. Set padSpace: true to keep the element width stable during animation.

Loading system...
gsap.to("#obj-text", { duration: 2, text: { value: "System ready. All processes nominal.", padSpace: true // pads with spaces to keep width }, ease: "none" });
02 — Delimiter

delimiter — word-by-word

By default text is revealed one character at a time. Set delimiter to " " to reveal word-by-word, or any other character.

delimiter: " " — word-by-word

Try different delimiters to change how the text is chunked during animation.

Choose a delimiter above
waiting…
gsap.to("#delim-text", { duration: 3, text: { value: "One small step, for a man, one giant leap", delimiter: " " // "" = char, " " = word, ", " = phrase }, ease: "none" });
03 — Typewriter

Typewriter cursor effect

Combine TextPlugin with a blinking cursor pseudo-element to build a classic typewriter effect.

Typewriter with blinking cursor

The cursor blinks via CSS animation. Typing pauses using gsap.delayedCall() between phrases.

const phrases = ["Build animations.", "Ship fast.", "GSAP is magic."]; function typeNext(i) { gsap.to("#el", { duration: phrases[i].length * 0.07, text: { value: phrases[i], delimiter: "" }, ease: "none", onComplete: () => gsap.delayedCall(1.5, () => { gsap.to("#el", { duration: 0.5, text: "", ease: "none", onComplete: () => typeNext((i + 1) % phrases.length) }); }) }); }
04 — Sequence

Timeline text sequences

Add text tweens to a timeline to chain text changes with precise timing and overlaps.

Timeline-driven text reveal

Each text tween is placed in a timeline with a label. The whole sequence plays in order with controlled pauses.

STATUS OUTPUT
const tl = gsap.timeline(); tl.to("#el", { duration: 0.6, text: "Connecting...", ease:"none" }) .to("#el", { duration: 0.6, text: "Authenticated.", ease:"none", delay:0.8 }) .to("#el", { duration: 0.8, text: "Loading modules...", ease:"none" }) .to("#el", { duration: 1, text: "System online. Welcome back.", ease:"none", delay:0.5 });
05 — Multi-target

Multiple elements + stagger

Use stagger with text tweens to reveal multiple elements one after another.

Staggered multi-line reveal

Each line reveals its text staggered 0.3s apart. Great for list reveals or code block animations.

const lines = [ "→ npm install gsap", "→ import gsap from 'gsap'", "→ gsap.registerPlugin(TextPlugin)", "→ gsap.to('.el', { text: 'Hello!' })" ]; gsap.to(".multi-item", { duration: 0.8, text: (i) => ({ value: lines[i] }), ease: "none", stagger: 0.4 });
06 — Speed Control

speed — characters per second

Instead of setting duration manually, use the speed property to define characters-per-second. Duration scales with text length automatically.

text: { speed } — auto duration

The tween duration is calculated as charCount / speed. Longer texts take longer but maintain the same pace.

choose a speed above
gsap.to("#speed-text", { text: { value: "The quick brown fox jumps over the lazy dog.", speed: 60 // 60 characters per second; duration = length / speed }, ease: "none" });

newClass — style mid-animation

New characters are placed in a newClass span that is removed when the tween completes. Style it with CSS for a highlight-as-you-type effect.

gsap.to("#newclass-text", { duration: 3, text: { value: "New characters glow as they appear.", newClass: "highlight-new" // applied to newly-typed chars }, ease: "none" });
